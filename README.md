🔗 **Sitio en vivo:** [gimenezwebfixer.com](https://gimenezwebfixer.com)

---

## 🚀 Propósito del Proyecto

GimenezWebFixer fue diseñado y desarrollado con una estética minimalista, elegante y de alto contraste (estilo monocromático corporativo) para transmitir confianza, rapidez y solvencia técnica directa a clientes que necesitan solucionar problemas en sus sitios web de manera urgente.

---

## 🛠️ Tech Stack & Herramientas

* **Frontend Framework:** React 18 + Vite (para builds ultrarrápidos)
* **Estilos & UI:** Tailwind CSS (diseño responsive fluido y componentes custom)
* **Iconografía:** Lucide React / Vectores optimizados
* **Optimización & SEO:** Etiquetas Open Graph (OG), Twitter Cards, Sitemap XML indexado en Google Search Console y robots.txt
* **Despliegue & Hosting:** Producción estática desplegada en Hostinger

---

## ✨ Características Clave

* ⚡ **Performance Extrema:** Tiempos de carga mínimos gracias al empaquetado optimizado de Vite.
* 📱 **Mobile-First Responsive:** Adaptabilidad absoluta a smartphones, tablets y pantallas de escritorio.
* 🔍 **SEO Técnico Completo:** Metadatos configurados para previsualizaciones impecables en WhatsApp, LinkedIn y buscadores.
* 🛠️ **Enfoque de Conversión:** Estructura clara orientada a la contratación directa de servicios técnicos y contacto rápido.

---

## 💻 Desarrollo Local y Compilación

Para correr el proyecto o generar una nueva versión de producción (`dist/`):

* Clonar repositorio: `git clone https://github.com/SebaGimenezOk/gimenezwebfixer.git`
* Entrar al directorio: `cd gimenezwebfixer`
* Instalar dependencias: `npm install`
* Iniciar servidor de desarrollo: `npm run dev`
* Generar build de producción: `npm run build` *(la carpeta resultante `dist/` se utiliza para el deploy en Hostinger)*
