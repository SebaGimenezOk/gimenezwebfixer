🔗 **Demo en vivo:** [portfolio2026-puce-three.vercel.app](https://portfolio2026-puce-three.vercel.app)

---

## 🛠️ Tech Stack & Herramientas

* **Frontend Framework:** React 18 + Vite
* **Estilos & UI:** Tailwind CSS (diseño responsive, estética minimalista monocromática)
* **Iconografía & Assets:** Lucide React / SVG vectoriales optimizados
* **Despliegue & Hosting:** Vercel CI/CD
* **Control de Versiones:** Git / GitHub Workflow (`main` & `develop`)

---

## ✨ Características Clave

* 🚀 **Alto Rendimiento:** Build optimizado con Vite para tiempos de carga y rendering mínimos.
* 📱 **Diseño Responsive & Fluid:** Adaptabilidad total desde mobile hasta pantallas ultrapanorámicas.
* 🔍 **SEO & Metadata:** Integración de etiquetas Open Graph, Twitter Cards, `sitemap.xml` y `robots.txt` para indexación óptima en buscadores.
* 💼 **Showcase Interactivo:** Exposición de proyectos destacados (Web, Native Mobile, Data Analytics) con modales interactivos y enlaces a producción.
